MUSORDROP simulator — Игра в терминале про кейсы.

Симулятор открытия кейсов на Python. Фарми баланс, открывай кейсы, ставь ставки, подключай 6G, заводи тамагочи и создавай свои моды — всё прямо в терминале.

## 🚀 Быстрый старт

1. Скачай MUSORDROP.py
2. Запусти: `python MUSORDROP.py`
3. Введи ник (русские буквы, 3–15 символов)
4. Придумай пароль (мин. 4 символа)
5. Фарми баланс и открывай кейсы!

Требуется Python 3.8+. Никаких сторонних библиотек — всё встроенное.

## 🎮 Что есть в игре

### 🎰 Кейсы
- Обычный кейс — 5₽ за открытие
- Кейс стран — 50₽, призы от 300₽ до 15000₽ + бонусы
- Редкости: от ⚪ Комонки до 🎉 УЛЬТРА ЛЕГЕНДАРКИ
- Ошибки сервера — иногда кейс ломается и игра закрывается 😈

### 💰 Экономика
- Баланс — твои деньги
- Ставки — рискни деньгами на редкость (x1.5 – x10)
- Скилл фарма — статистика: прибыль, ROI, уровень

### 🐕 Тамагочи (от 500₽)
- Выбери питомца: пацан или девка
- Дай ему имя
- Следи за голодом, здоровьем, настроением
- Магазин — в разработке 👀

### 🔐 Система паролей
- SHA-256 + соль
- 4 попытки — сброс пароля
- Ещё 4 промаха — полный сброс аккаунта 💀

### 📡 6G и серверы
- Подключение к 6G вышке (рандом)
- Проверка своего сервера по URL
- Проверка помощника разраба

### 📊 Прочее
- 🏆 Топ-5 лучших дропов
- 📅 Страйк (ежедневные заходы) + заморозки
- 📚 Проверка стиха Тютчева «Листья» (+5000₽ за знание)
- 😂 Спиночесалка (рофл)
- 📝 Лог импорта модов

## 📦 Моды

Моды — это JSON-файлы. Кладёшь их в папку `modloader/`, игра сама их подхватит.

Пример мода:

```json
{
  "name": "Мой мод",
  "author": "твой_ник",
  "version": "1.0",
  "start_balance": 500,
  "rarities": [
    {"name": "🌈 МИФ", "chance": 0.01, "message": "МИФ!"}
  ],
  "countries": [
    {"name": "🇯🇵 Япония", "chance": 0.15, "prize": 2000}
  ]
}
```

Редактор модов — HTML-файл, создаётся автоматически в папке сохранений. Открой в браузере и собери мод мышкой.

## 🗂 Где хранятся сохранения

- Android: `/storage/emulated/0/.musordrop/`
- Windows: `%APPDATA%\musordropdata\`
- Linux: `~/.musordrop/`
- macOS: `~/musordropdata/`

Внутри:
- `mods/` — установленные моды
- `modloader/` — откуда подхватываются моды
- `mds/` — документация
- `temp/` — временные файлы + `process.log`
- `drops_log.csv` — лог всех дропов
